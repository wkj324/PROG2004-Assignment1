This is an object-oriented Java program for medical appointment management.
## Features
- Different types of health professionals (Doctor, Surgeon, Nurse, Dietitian, Physiotherapist, Pediatrician)
- Add, view, cancel and modify appointments
- Input validation for appointment time
- Console interactive menu for user operation

## OOP Concepts Applied
- Abstract class
- Inheritance
- Polymorphism
- Encapsulation
